# Kalakalyani

Psychologist & Counsellor, Thrissur

A calm, single-page website for Kalakalyani, a psychologist with over thirty years of practice in Thrissur, Kerala. The site presents her services — personal counselling, career and study guidance, and classes and workshops — with a gentle, welcoming tone, plus clear fees and a simple contact flow.

Live site: [https://ishatxt.github.io/kalakalyani/](https://ishatxt.github.io/kalakalyani/)

## Features

- Single-page layout with sections for About, Services, Classes, Approach, Fees, Testimonials, and FAQ
- Fee estimator to help visitors gauge costs by session type, audience, and format
- WhatsApp and email contact options, plus a contact form
- Responsive design for mobile and desktop

## Tech Stack

- HTML
- CSS
- JavaScript

## Getting Started

Open `index.html` in any browser, or serve the directory locally:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`.

## Deployment

The site is deployed with GitHub Pages from the `main` branch.
